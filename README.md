## Descripción

Repositorio académico del curso de **Estadística Espacial**, destinado a organizar las prácticas, evidencias, datos y proyectos desarrollados mediante sistemas de información geográfica.

Los trabajos integran conceptos estadísticos y geoespaciales para representar, explorar y analizar fenómenos distribuidos sobre el territorio, empleando principalmente **QGIS**.

## Modelos de datos espaciales

| Modelo | Representación | Aplicación realizada |
|---|---|---|
| Ráster | Matriz de celdas con valores espaciales | Modelo digital de elevación de Puno |
| Vectorial | Puntos, líneas o polígonos definidos mediante coordenadas | Límites de las 13 provincias de Puno |

## Herramientas y formatos

- **QGIS 3.44.14 Solothurn:** visualización y procesamiento geoespacial.
- **GeoTIFF (`.tif`):** almacenamiento del modelo digital de elevación.
- **GeoPackage (`.gpkg`):** almacenamiento de los límites provinciales.
- **Git y GitHub:** organización, documentación y publicación de evidencias.
- **EPSG:4326:** sistema de referencia geográfica empleado.
